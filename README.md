App Name : AppZone.Io

Description : In this app you can easily found app what our company builts . in home page you can see a attractive ui and  information. if you click on app card you will go app details page. there you will see install Now button . if you click on this button this app id stored in local storage , button will be disabled and button text will change to installed. if you go apps page you will see number of apps , search ber and apps card. you can search app live. if there is no app what are searching then you will see app not found.app you click on app card you will go app details page. if you go installation page you will see installed app . if you click on unstall button you will unstalled this app and also app id removed from local storage. if go app details route and if there is no app on this id you will see app not found page. if you go an invalid route you will see a error page.

technology: html,css,react js, tailwind css, daisy ui etc.
